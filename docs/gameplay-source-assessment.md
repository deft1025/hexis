## 数据适配

我们以当前版本的英雄 `riot_id`、海克斯 `riot_id`、装备 ID 建立关联。站点路径名、中文别称、推荐标签不能直接当作本项目 ID，也不能仅凭同名判定效果一致。每条玩法需要分类、适用英雄、推荐理由、出装阶段、触发条件、限制和来源。

网页只给出推荐清单时，不能补写未经验证的触发机制。来源中的强度标签与“最高胜率”不导入。网页更新时间不能当作游戏版本；国服公告的 `26.20` 与资源版本的 `16.20.1` 也不能仅通过文字替换判定一致。

本地装备说明仍有动态模板解析不完整的字段，例如心之钢的冷却占位、狂徒回复数值，不能据此写死具体数值。对机制的推断也须与国服游戏内描述和实战核对。
